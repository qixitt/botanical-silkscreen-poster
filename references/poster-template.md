# 海报生成模板

用实际内容替换 {字段}；《》标记准确文字而不作为印刷字符。不要将本文件的说明或占位符打印到画面。

复古丝网印刷植物图鉴海报，纵向画幅，沿用植物参考图的长宽比。米白色微粗纹理纸张，东方现代杂志式排版，干净、安静、雅致，保留留白。仅出现下面明确指定的文字，不添加编号、年份、水印、署名、额外英文译文或装饰文字。

植物构图：以用户照片为唯一植物内容和布局依据，保留全部花头、花苞、花茎、叶片及周边植物的数量、位置、大小比例、朝向、倾斜角度、分叉关系、前后遮挡关系及原有裁切。不得增加、删除、单独旋转、移动或重新组合植物元素。为避免文字遮挡花叶，允许将植物作为一个整体等比例适度缩小并平移，保持所有花叶的相对位置、比例、姿态和遮挡关系。文字区域需留出干净纸面及间距。非植物摄影背景替换为米白纸面，去除背景杂物。文字放在现有空白区域，避免遮挡花头、花苞及关键茎叶。

画法：平面植物插画，以清晰大色块概括花瓣、叶片，沿自然轮廓适度几何化，保留柔和弧线和花瓣层叠。各部位采用自身同色系的深浅色块，局部半透明薄墨叠印，纸色透出、重叠处略深。渐变柔和克制，块面清楚，避免过度碎化、厚涂、塑料高光和立体渲染。花茎和叶片保留参考照片的对应色相，不统一染成花瓣色。植物带细腻丝网颗粒，背景淡纸纹，文字边缘清楚，印章轻微缺墨，整体不脏不糊。

版式：非对称且视觉均衡的七区排版，各区按统一网格对齐，外边距一致，信息区清晰分开。主标题最醒目，顶部外文次之，辅助小字克制但可读。长文本允许在所属区域内自然换行，不删改文字、不相互覆盖。

1. 左上角：超大号竖排复古宋体中文花名《{花名}》，字形端正、粗细对比鲜明。右侧紧邻较小竖排花语《{花语}》，保留斜杠。花语正下方一枚小巧朱红色方印，印内篆书“花语”二字。这是全图唯一的朱红色装饰印章。

2. 顶部正中：流畅、优雅且可辨读的手写花体《{学名}》。正下方居中一行小号中文《一朵花的自述》。字母完整，拼写准确，层级清楚，行距舒适。

3. 右上角：两行小字，统一右对齐，字号行距一致：
《养护水位：{养护水位}》
《换水周期：{换水周期}》

4. 左侧下方：单列纵向信息区，各项左对齐，以短横线引导，条目间距一致。长条目续行与正文对齐：
《-学名：{学名}》
《-原产地：{原产地}》
《-别名：{别名}》
《-花语：{花语}》
仅这四项，不添加养护花期、上市季节或翻译。

5. 左下角：小型双圆环复古印章，内环上半圈《{花名}》，下半圈《{学名}》。文字清楚，不加年份、编号。印章整体与中文大标题完全同色，不能另用朱红色。

6. 画面最右侧中间：竖排《{科属}》，中文自上而下，沿右侧版心对齐，与裁切边缘保持安全距离，不额外添加外文。

7. 右下方：上行中文《{中文短句}》，下行英文《{英文短句}》。中文用清雅宋体，英文用协调的衬线字体，文字组在本区居中对齐。下方一行全大写《GENGYANLI FLOWERS》，适度拉开字距，旁边一个极小的对应植物线条图标，与文字同色。（图标属于版式装饰，不计入照片植物数量。）

全局配色：从花瓣主色提取低饱和深色，作为大标题与左下圆印的相同墨色。其余文字使用同色相、清楚可读的深色。若花瓣近白色，从花瓣阴影提取较深的灰调色以保证对比度。除左上朱红方印之外，文字与装饰不另加高饱和强调色；植物保留协调的自身花叶配色。

所有指定文字完整准确，无错字、乱码、畸变、糊字或越界。优先植物构图忠实、文字完整和互不遮挡，再保持轻薄叠印质感与留白。
