# 花卉丝网印刷海报 · Botanical Silkscreen Poster

将一张花卉参考照片与简短植物资料，转化为统一风格的复古植物图鉴海报。

![海报效果示例](assets/approved-style.png)

## 简介

本项目是面向支持图像生成的 Codex 环境的 Skill，包含生成指令、七区海报模板、十组中英诗句和风格参考图。它不是独立绘图软件，也不附带模型服务。调用时需要宿主环境提供图像生成与参考图编辑能力。

视觉风格为米白纸纹、半透明色块叠印与细腻丝网颗粒，配合东方杂志式排版。保留参考植物的数量、姿态和内部相对布局，并允许整体缩小、平移，为文字留白。

## 安装

1. 下载本仓库，保留整个文件夹及其内部目录。
2. 将文件夹命名为 `botanical-silkscreen-poster`，放入个人技能目录：通常是 `~/.codex/skills/`；设置了 `CODEX_HOME` 时使用其下的 `skills/`。
3. 在能够发现该技能且具备图像生成能力的 Codex 会话中调用。若当前会话未识别，重新打开会话后检查技能列表。

安装后的结构应为 `~/.codex/skills/botanical-silkscreen-poster/SKILL.md`，避免重复嵌套同名文件夹。仅上传 GitHub 不会自动安装到 Codex。

## 快速使用

在对话中输入下面的内容，并附上对应花卉参考照片：

```text
使用 $botanical-silkscreen-poster 生成海报。

花名：芍药·绿韵
学名：Paeonia lactiflora
花语：情有独钟 从一而终
科属：芍药科芍药属
别名：将离、婪尾春
原产地：中国及亚洲北部
养护水位：瓶插宜深水，约2/3
换水周期：每天换水
```

也可以在已经启用此技能的连续对话里直接发送花卉资料和照片。以上文字仅是使用示例，每次应填写与照片对应的资料。

## 输入规则

| 输入 | 用途 |
|---|---|
| 花名 | 左上标题、左下圆形印章 |
| 学名 | 顶部花体名称、信息区、圆形印章 |
| 花语 | 标题旁竖排文字、信息区 |
| 科属 | 右侧竖排文字 |
| 别名 | 左下信息区 |
| 原产地 | 左下信息区 |
| 养护水位 | 右上养护说明 |
| 换水周期 | 右上养护说明 |
| 植物照片 | 花头、花苞、茎叶数量与内部构图依据 |

缺少必需字段或对应照片时，技能会向用户索要。不会自行编造或沿用其他花卉资料。养护花期、上市季节等模板外字段不加入海报。默认按用户提供的信息排版，不把生成过程当作植物学核验；如需核实资料，可另行明确请求。

## 固定文案与版式

- 副标题固定为“一朵花的自述”。
- 系列名固定为“GENGYANLI FLOWERS”。
- 右下短句从十组诗句中随机选一组，中文在上、对应英文在下。用户明确指定时使用指定内容。
- 左上中文标题及花语、顶部外文与副标题、右上养护信息、左下植物信息、左下圆印、右侧科属、右下短句及系列名，共七区。
- 文字与圆印从花瓣色系提取低饱和深色；近白花从阴影色取色。仅左上小方印使用朱红色。
- 植物可整体等比例缩小并平移以避免遮字，不单独重排花叶。

## 参考图与生成结果

`assets/approved-style.png` 是本工作流生成并经用户选定的风格示例，仅参考纸张、叠印、字体层级和版式气质。每次的新花卉照片才是主体与构图依据，不会直接把示例中的百合套用到新海报。

默认每次生成一张。成图会检查文字、区块、花叶遮挡与构图，明显问题最多进行两次针对性修正。生成模型可能出现错字、微小形态变化或位置偏差，无法保证像素级复刻；正式使用前仍应检查成品。

需持久交付时，成品及实际提示词保存到当前工作区 `output/botanical-posters/`，不覆盖已有作品。

## 如何调整

可以直接在对话里提出，例如：

```text
把植物整体缩小一些，让左下信息区不遮挡叶片，保持花叶的相对布局。
```

要长期更改规则，可编辑：

- `SKILL.md`：输入规则、工作流程及检查标准。
- `references/poster-template.md`：七区布局、固定文字和绘画风格。
- `references/couplets.md`：中英文短句库。
- `agents/openai.yaml`：界面显示名称和默认调用提示。
- `assets/approved-style.png`：风格参考图。

替换系列品牌文字时，请同步修改 `SKILL.md` 与海报模板。模板里的《》用于标记待显示的文字，书名号本身不印入画面；（）内是执行说明，不打印。
